- **Logic Pro runs on ClokeOS (arm64).** Apple's Logic Pro 12 (not included: you bring your own copy) starts in the arm64 VM on Darling's Mac frameworks, opens a project (the "Jump" demo), draws its main window with track headers, the arrange area with regions and notes, the LCD (position, tempo, key), the inspector and the toolbar menus. The audio engine runs on a new CoreAudio shim; an offline bounce of the demo song matches a bounce from a real Mac, ALAC and CAF audio decode, and real-time playback starts but is not steady yet. Still open: some drawing details (bar lines, region names), plug-in windows, real-time playback, x86_64. See `docs/logic-launch.md` and `docs/audio-stack.md`
- **Mac apps, much further:** a real Swift runtime (arm64 and x86_64), a Foundation Swift overlay, SwiftUI/Combine placeholder types, CoreData with in-memory stores, Core Text and AppKit text layout like Apple's (attribute keys, line fragments, drawing in flipped and unflipped views), view-based tables, asset catalogs, NIBArchive nibs, a `.pkg` installer (`clokeos-pkginstall`), C libraries with Apple install names (sqlite3, xml2, bz2, pcre, xar), Carbon Time Manager, 33 stub frameworks for closed-source imports
- **Windows programs through Raven (x86_64 and now arm64):** Notepad++ runs with a macOS title bar, all its menus in the ClokeOS menu bar, its icon in the Dock, file dialogs and the clipboard in both directions. 32-bit programs run; NSIS, Inno Setup and MSI installers run (the Inno Setup wizard installs from first page to last, and the installed Inno Setup Compiler starts). Start Menu shortcuts of installed programs become applications in `~/Applications`; the C: drive is the shared `/NT` tree with a folder per user. Wine is gone from the image
- **Raven on arm64:** a new backend runs the program's x86-64 code through Unicorn, 64-bit and 32-bit; with `RAVEN_JIT=1` it uses ClokeOS's own block JIT instead
- **x86 to arm translation is much faster.** The block JIT (`UCRUN_JIT=1` for Mac programs, `RAVEN_JIT=1` for Windows programs) now translates SSE, SSE2, SSSE3, SSE4.1, optional AVX/AVX2 (`RAVEN_JIT_AVX=1`), atomics, rotates, bit scans and bit tests, protects translated pages and notices self-modifying code. Measured on integer kernels (ms, Apple silicon, other VMs running): sieve 57 (Rosetta 2: 110), fib(35) 39 (42), collatz 155 (221), crc32 9 (14), 200x200 matrix 4 (3), byte copy 11 (17), div/mod 4 (7). That is 0.85 to 2 times Rosetta 2 and 3 to 180 times faster than the Unicorn interpreter; 8 x 60,000 random instruction sequences against Unicorn show no mismatch. Details and the Raven numbers: `docs/translation-study.md`, `docs/raven-port.md`
- Title bars like macOS for every program (Mac, GTK, Windows): traffic lights, unified title bars in the program's colour, a Window menu in the menu bar
- Cloke Store (Launchpad): a graphical app store with Discover, categories, search and updates, installing through `cloke`; `cloke` is a package manager for the whole system (ClokeOS apps, Homebrew Big Sur bottles, Alpine packages through `tux`, Windows programs through Raven)
- Modern browser: Search runs on WebKitGTK (tabs, HTTPS, current HTML5/CSS/JS) on both architectures, installed from the add-on packages of this repository; NetSurf is the fallback
- Programs of the other CPU: x86_64 Mac programs on arm64 (`ucrun`) and arm64 Mac programs on x86_64 (`a64run`), started by double-click or from the Terminal
- Linux programs (`tux`): threads, `epoll`, `inotify`, sockets, `/proc`, name resolution; BusyBox and Debian command line tools run on both architectures
- Drivers for real PCs: USB keyboard and mouse no longer stall in a loop, the Realtek network driver recovers from receive overflows, HD audio is matched by device class, all CPU cores on the HP laptop; a live stick for driver work on other PCs
- The `clokefetch` logo is the new one everywhere (Terminal, greeting, prototype)
- Everything from 2.1 to 2.7 as well: Recovery and installer, Disk Utility with partitioning and .dmg, the NT interface, the updater, the new design, bash and Homebrew
